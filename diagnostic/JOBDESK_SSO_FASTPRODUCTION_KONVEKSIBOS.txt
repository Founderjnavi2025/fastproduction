1. TUJUAN UTAMA
============================================================

Mengintegrasikan FastProduction dengan KonveksiBos melalui
Single Sign-On (SSO).

Pengguna yang sudah login ke FastProduction dapat membuka
KonveksiBos melalui menu:

LAB PRODUCTION TOOLS

Pengguna tidak perlu login ulang secara manual ke KonveksiBos.

SSO harus menghasilkan sesi autentikasi KonveksiBos yang sah,
bukan hanya meneruskan UUID atau email dari FastProduction.

3. ATURAN IDENTITAS DAN SSO
============================================================

1. Identitas FastProduction menjadi identitas masuk awal.

2. Token FastProduction harus diverifikasi oleh server
   menggunakan Supabase Auth FastProduction.

3. Jangan percaya UUID atau email yang dikirim dari browser
   tanpa verifikasi token.

4. Jangan menganggap UUID kedua project Supabase sama.

5. Jangan menganggap email yang sama otomatis membuktikan
   kepemilikan akun KonveksiBos.

6. KonveksiBos harus memiliki sesi Auth sendiri.

7. Jangan pernah mengirim service_role key ke frontend.

8. Jangan menaruh secret di HTML atau JavaScript publik.

9. Jangan mengganti password akun lama tanpa persetujuan.

10. Jika email FastProduction belum terverifikasi atau kosong,
    harus ada penanganan yang aman.

============================================================
4. ATURAN WORKSPACE PEMILIK
============================================================

Saat pengguna FastProduction pertama kali membuka
Lab Production Tools:

- Server memverifikasi identitas FastProduction.
- Sistem memeriksa sso_identity_links.
- Jika belum ada tautan, sistem membuat atau menghubungkan
  identitas KonveksiBos secara aman.
- Sistem membuat satu workspace milik pengguna jika memang
  belum mempunyai workspace yang terhubung.
- Pengguna masuk sebagai pemilik workspace.

Saat pengguna membuka Lab berikutnya:

- Gunakan identitas KonveksiBos yang sama.
- Gunakan workspace yang sama.
- Jangan membuat room baru.
- Jangan menghapus atau mengosongkan data.
- Jangan mengulang migrasi data secara sembarangan.

Data yang wajib tetap tersimpan:
- Pekerja.
- Pekerjaan.
- Payroll.
- Riwayat produksi.
- Data workspace lainnya.

============================================================
5. ATURAN GUEST DAN BERBAGI WORKSPACE
============================================================

Contoh:

Bambang memiliki akun FastProduction dan workspace
KonveksiBos miliknya.

Dilraba Dilmurat membuka tautan workspace Bambang.

Hasil yang diharapkan:
- Bambang tetap OWNER.
- Dilraba masuk sebagai GUEST.
- Guest hanya boleh melihat data yang diizinkan.
- Guest tidak boleh mengubah atau menghapus data.
- Guest tidak boleh mengambil alih kepemilikan room.

Pemilik dapat mengundang pengguna dan memberikan
tingkat akses sesuai sistem izin yang dirancang.

CATATAN:
Guest merupakan fitur akses berbagi room, bukan mekanisme
SSO pemilik.

Skema room_members saat ini memiliki role:
owner, admin, gudang, obras, jahit, kam, kancing.

Role guest/editor/user belum tersedia pada constraint
yang teridentifikasi.

Jangan menambahkan role baru tanpa memeriksa seluruh
RLS policy dan fungsi database.

============================================================
6. ARSITEKTUR YANG DIHARAPKAN
============================================================

Alur:

1. Pengguna login ke FastProduction.
2. Pengguna membuka Lab Production Tools.
3. Browser mengambil sesi/token FastProduction.
4. Browser mengirim token ke Edge Function KonveksiBos.
5. Edge Function memvalidasi token ke Supabase FastProduction.
6. Server mencari mapping pada sso_identity_links.
7. Jika belum ada mapping, server melakukan provisioning
   identitas KonveksiBos dengan aman.
8. Server memastikan workspace pemilik tersedia.
9. Server menghasilkan mekanisme pertukaran sesi KonveksiBos
   yang aman dan hanya dapat digunakan oleh pemilik identitas.
10. Browser memperoleh sesi Supabase KonveksiBos.
11. KonveksiBos memuat workspace yang tepat.
12. Pengguna masuk tanpa login manual.

Perlu dirancang mekanisme:
- Pencegahan replay token.
- Validasi origin dan CORS.
- Penanganan permintaan berulang/idempotency.
- Penanganan kegagalan provisioning.
- Pencegahan akun ganda.
- Keamanan magic link/token exchange.
- Penanganan akun KonveksiBos lama.

Jangan menganggap rancangan pertukaran sesi sudah final
sebelum memeriksa API Supabase yang benar.

============================================================

[ ] Pengguna FastProduction yang login dapat membuka Lab.

[ ] KonveksiBos memiliki sesi Auth yang sah.

[ ] Data pekerja tidak hilang.
[ ] Data pekerjaan tidak hilang.
[ ] Payroll dan riwayat tetap ada.
[ ] Pengguna lain tidak otomatis menjadi pemilik.
[ ] Guest tidak dapat mengedit data.
[ ] Login manual KonveksiBos tetap berfungsi.
[ ] Logout ditangani dengan benar.
[ ] Tidak ada secret yang bocor ke frontend.
[ ] Tidak ada room duplikat akibat request berulang.
[ ] RLS tetap membatasi akses antar-room.

D. EDGE FUNCTION ADMIN LAMA

File:
supabase/functions/admin-create-account/index.ts

Temuan:
- Menggunakan service role di server.
- Memverifikasi caller melalui auth.getUser().
- Hanya super_admin yang diizinkan.
- Membuat user, profile, room, dan membership.
- CORS masih menggunakan wildcard (*).
- Melakukan profiles.insert setelah createUser.
- Melakukan room_members.insert setelah membuat room.
- Rollback menghapus profile dan auth user jika gagal.
- Rollback belum secara eksplisit menghapus room yang
  mungkin sudah berhasil dibuat.

E. TRIGGER DATABASE

Fungsi handle_new_room_owner():

- Otomatis memasukkan owner ke room_members.
- Menggunakan ON CONFLICT (room_id, user_id) DO NOTHING.

Implikasi:
Edge Function admin-create-account juga memasukkan owner
secara manual. Periksa apakah insert manual tersebut
sebenarnya masih diperlukan.

Fungsi handle_new_user():

- Memasukkan data ke profiles berdasarkan auth.users.
- Perlu periksa apakah trigger yang memanggil fungsi ini
  benar-benar aktif pada database saat ini.

Jika trigger aktif, profiles.insert manual di
admin-create-account berpotensi konflik.

Jangan mengasumsikan trigger aktif hanya karena fungsi
tersedia di schema.

F. SSO BELUM ADA

- Edge Function fastproduction-sso.
- Pertukaran token FastProduction ke sesi KonveksiBos.
- Integrasi tombol Lab Production Tools.
